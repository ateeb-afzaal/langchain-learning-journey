# 02 — LangChain Components

## Overview

LangChain provides reusable components that help developers build applications powered by Large Language Models (LLMs).

In this section, we learn the six main components introduced in the CampusX LangChain course.

## Topics Covered

1. **Models** — Connect applications to language and embedding models.
2. **Prompts** — Create instructions for language models.
3. **Chains** — Connect multiple steps into a workflow.
4. **Indexes** — Organize and retrieve information from external knowledge sources.
5. **Memory** — Maintain conversation context.
6. **Agents** — Allow language models to select and use tools.

## Learning Objectives

By the end of this section, I should be able to:

- Explain the purpose of each LangChain component.
- Understand the difference between a chain and an agent.
- Understand why applications need external knowledge.
- Explain how conversation history works.
- Identify which components are needed for different AI applications.
