# 01 — Introduction to LangChain

## What is LangChain?

LangChain is an open-source framework that helps developers build applications powered by Large Language Models (LLMs).

It provides reusable components for connecting AI models with prompts, data sources, external tools, and application logic.

## Why do we need LangChain?

Without LangChain, developers may need to write separate code for interacting with models, connecting multiple steps, retrieving information, and managing conversations.

LangChain makes these tasks easier by providing a common framework.

## Benefits of LangChain

- Supports different language models.
- Simplifies LLM application development.
- Connects AI models with external tools and data.
- Provides reusable components for complex workflows.
- Supports RAG, chatbots, and AI agents.

## What can we build?

- Conversational chatbots
- AI knowledge assistants
- RAG-based question-answering applications
- AI agents
- Workflow automation
- Document summarization tools

## Alternatives

- **LlamaIndex:** Particularly useful for building applications involving external data and retrieval.
- **Haystack:** A framework for search, question answering, and RAG pipelines.

## Key Takeaway

LangChain helps developers move from simple LLM API calls to applications that combine models, prompts, data, tools, and workflows.
